What I learned:

The thing that instantly caught my eye was the keyword protected. Basically, it is used as another private keyword, but is used specifically
for accessability in the package or a subclass. I didn't think this was good enough so I decided to look further and look for something else
I haven't seen before. The extended keyword is the next thing that caught my eye. This keyword is used to create a version of a class already 
made, where this new version can have the same methods and functions from the "parent" class. This is found in the Enemy.java file and the
Player.java file where they both extend off of the character class. This is useful as instead of copying over the same methods and functions
from the already made class, you can just extend them over into a new class without having to type it all out.
